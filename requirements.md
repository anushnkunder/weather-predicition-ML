# Requirements

## Python Version
- Python 3.10+

## Third-Party Packages
Install with:

```bash
pip install pandas scikit-learn matplotlib seaborn jupyter ipykernel
```
# Packages used
Package list:
- pandas
- scikit-learn
- matplotlib
- seaborn
- jupyter
- ipykernel

## Standard Library Modules (already included with Python)
- os
- json
- logging
