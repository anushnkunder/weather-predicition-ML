# Requirements

## Python Version
- Python 3.10+

## Third-Party Packages
Install with:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter ipykernel xgboost shap streamlit joblib
```

Package list:
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
- jupyter
- ipykernel
- xgboost
- shap
- streamlit
- joblib
- plotly

## Standard Library Modules (already included with Python)
- os
- json
- logging
